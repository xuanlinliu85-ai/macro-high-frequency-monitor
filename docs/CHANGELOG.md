# Changelog

## 1.0.0 — 2026-09-12

首个独立发行版本。方案从原工作仓库中抽离为**自包含仓库**，不再依赖任何外部目录。

### 新增

- **日报「今日显著偏离」章（第 2 章）** —— 回答「今天什么变了、变得离不离谱」。
  - 新增核心量 `chg1Extreme`：本期 `|1 期变化|` 在**该指标自身近 3 年单期变化分布**中的分位。
    选用它有明确理由：`z1y` 只说明"现在位置高不高"，回答不了"今天这一下变化大不大"。
  - 结构：结论句 → 上涨侧榜 / 下跌侧榜（各 6 项）→ 月频季频单独成表 → 加注口径。
  - 固定标注词表：`刷一年新高/新低`、`变化极端`、`变化显著`、`位置极端`、`变化+位置双极端`、`持仓放大`。
  - **涨跌按原始方向**标注（回答"涨跌"不是"好坏"）。
  - **双层去重**：宏观层的「XX主力」期货收盘价指标与期货层是同一标的，只保留带持仓量的期货层。榜单 36 → 33 项，无重复标的。
  - 口径详见 `docs/DEVIATION_RULES.md`。
- **工作台「今日全景」引用同一结论句** —— 两处同源，不会各说各话。

### 修复

- **图表自检漏判**：原自检只查**容器**尺寸，抓不到「容器有宽高、canvas 却是 0×0」这个最阴的失败形态，
  导致"面板没图"依旧静默通过。改为查 **canvas 像素**并按 `devicePixelRatio` 折算比对。
- **单图失败中断整页**：`drawLine` / `mk` 均包 `try/catch` 并登记 `RENDERERS[nodeId]` 重画入口，
  新增 `window.__macroRedraw__()` 一键重画；重画前 `dispose` 旧实例避免泄漏。
- **兜底触发不足**：补 `IntersectionObserver` + `visibilitychange` + 多时间点 `resize()`
  （原只有 `ResizeObserver`），覆盖 iframe 首帧 / 折叠 / 预览面板场景。
- **品种热力图画不全**：`futHeatChart` 漏登记 `CHARTS` / `RENDERERS`，canvas 被裁成 100px 宽。
- **`CAT_CN_OF` 未定义**：新增章节调用了它，但此前只有函数内部的局部 `CAT_CN`。
  已把板块中文名提到模块级并让「全指标总表」复用同一份，消除重复定义。
- **模板放在被 gitignore 的 `work/` 里**：模板是**源码**不是产物。后果是新克隆只能看到 2 MB 的生成结果，
  看不到产出它的源码。→ 迁至 `templates/macro/workbench.template.html`。
- **配置真源在仓库外**：`macro-config.mjs` 原先写死一个仓库外的绝对路径。
  → 迁入包内 `references/`，改为「就近优先」定位（环境变量 → 脚本上级 → 包内），
  找不到时抛**带指引的错误**而不是静默用死路径。
- **主力合约缓存路径写死**：`macro-main-contract.mjs` 的 `CACHE_PATH` 原先写死绝对路径。
  → 由脚本位置推导 + 环境变量覆盖。

### 新增工具

- `scripts/verify.mjs` —— 只读自检 7 项：配置真源可定位、注册表可解析、知识层齐备、
  代码层无写死绝对路径、工作台可离线构建、快照契约含 `chg1Extreme`、日报含显著偏离章。
- `scripts/macro-install-skill.mjs` —— 把本包装配安装到 agent skills 目录（默认 `~/.codex/skills/`），
  带 `--check` 装配体检（清单齐备 / 无死路径 / 注册表可解析）。
