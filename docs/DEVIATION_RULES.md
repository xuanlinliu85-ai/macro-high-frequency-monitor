# 「今日显著偏离」判定口径

> 回答的问题：**「今天什么变了、变得离不离谱」。**
> 这一章要给出**结论**，不是罗列数字。

## 为什么需要它

原来的日报能告诉你"某个指标现在处于历史高位"，但回答不了"今天这一下变化是不是罕见"。
两者的信息量完全不同：一个指标可以**位置很中性、今天却跳了一记大变化**。

## 核心量：`chg1Extreme`

```text
chg1Extreme = 分位_of( |本期 1 期变化| , 该指标自身近 3 年全部单期 |变化| 的集合 )
```

**用自身历史做基准，不用跨指标比较** —— 因为"农产品单日波动 1.7%"和"国债收益率单日变动 1.7bp"
本来就不在同一个尺度上，跨指标比大小毫无意义。

### 为什么不用 `z1y`

`z1y` 是**位置**度量（当前值在近 1 年的 z 分数），回答"现在高不高"。
它**不是变化**度量，回答不了"今天动得大不大"。二者互补，不可互相替代：

| 情形 | `z1y` | `chg1Extreme` | 含义 |
|---|---|---|---|
| 长期高位横盘，今日小动 | 高 | 低 | 位置极端，但今天没新信息 |
| 位置中性，今日跳涨 | 中性 | 高 | **今天出现了新信息** ← 这一章要抓的 |
| 长期高位，今日再冲 | 高 | 高 | 双极端，最值得看 |

## 阈值（集中在 `macro-report.mjs` 顶部 `THRESH`）

| 常量 | 值 | 含义 |
|---|---|---|
| `chgExtreme` | `0.90` | 本期 \|1 期变化\| 进入自身近 3 年变化分布**前 10%** → 当日偏离 |
| `chgExtremeStrong` | `0.97` | **前 3%** → 措辞升级为「极端」 |
| `zExtreme` | `2` | \|z(1Y)\| ≥ 2 → 统计极端 |
| `pctHigh` / `pctLow` | `0.99` / `0.01` | 1 年分位 ≥99% / ≤1% → 刷一年新高 / 新低 |
| `oiSurge` | `0.30` | 期货持仓量 5 日变化 ≥30% → 持仓放大 |
| `deviationTop` | `6` | 涨/跌榜各取几项 |

## 固定标注词表

标注词是**固定词表**，不允许自由发挥，以便逐条复核：

| 标注 | 触发条件 |
|---|---|
| `刷一年新高` | `pct1y ≥ 0.99` |
| `刷一年新低` | `pct1y ≤ 0.01` |
| `变化+位置双极端` | `chg1Extreme ≥ 0.90` **且** `\|z1y\| ≥ 2` |
| `变化极端` | `chg1Extreme ≥ 0.97`（未同时满足位置极端） |
| `变化显著` | `chg1Extreme ≥ 0.90`（未达 0.97，且位置不极端） |
| `位置极端` | 变化不够极端，但 `\|z1y\| ≥ 2` |
| `持仓放大` | 期货品种 `\|oiChg5\| ≥ 0.30` |

## 入选规则

一个项目进入榜单，满足**任一**条件即可：

```text
chg1Extreme ≥ 0.90
OR  |z1y| ≥ 2
OR  pct1y ≥ 0.99 / ≤ 0.01
```

## 章节结构

```text
结论句   —— 共几项、涨/跌各几项、最极端的是谁、幅度、在自身 3 年里排到第几十分位
上涨侧榜 —— 按变化极端度排序，取前 6
下跌侧榜 —— 按变化极端度排序，取前 6
月频/季频单独成表 —— 标注「观测期不一定是今天」，与当日口径区分
加注口径 —— 把上面的判定规则写清楚，供复核
```

**结论句长这样**（真实格式）：

> 本日共 33 项出现显著偏离（按原始涨跌方向计：上涨 16 项、下跌 17 项，其中 1 项属于近 3 年最极端的 3% 变化）。
> 最极端的是 **花生**（农产品）本期 **-1.7%**，该幅度在自身近 3 年中排到第 **100** 分位，z(1Y) -2.31。

## 两条口径纪律

### 1. 涨跌按原始方向，不做方向校正

这一章回答的是**「涨跌」**，不是**「好坏」**。
所以用原始变化方向，`dirZ` 不参与这里的涨跌判断 —— 猪肉价格涨了对宏观未必是好事。

### 2. 双层去重

宏观层有一批「XX主力」的期货收盘价指标（沪铜主力 / 原油主力 / 铁矿石主力 / 螺纹钢主力 …），
它们与期货层是**同一标的**。若不去重，同一行情会在榜上出现两次。

去重规则：把宏观指标名末尾的「主力」去掉后与期货品种名比对；
命中则**只保留期货层**（期货层口径更全，带 `oiChg5` 持仓量与产业链分组）。

实测效果：榜单从 36 项收敛到 33 项，无重复标的。

## 月频 / 季频为什么要单独列

月频指标的「最新一期」可能是一个月前的观测（发布有滞后）。
把它们混进"当日"榜单会造成误读，因此单独成表并显式标注**观测期不一定是今天**。

## 工作台同步

- 日报该章由工作台「每日汇报」面板动态渲染（`report.json → sections[id=deviations]`），自动出现。
- 工作台「今日全景」**直接引用同一段结论句**，保证两处同源、不会各说各话。

## 可继续改进的方向

1. **对高波动品种做波动率归一化**。农产品单日 1.7% 与国债单日 1.7bp 都用"自身分位"衡量已经缓解了尺度问题，
   但农产品日内波动本身更大，前 10% 的门槛相对更容易触发 —— 可考虑对分位再按波动率做一层调整。
2. **加入方向一致性的确认**。目前只看单一指标，若同一维度内多个指标同日同向偏离，信号强度应更高。
3. **与背离规则联动**。当"当日显著偏离"集中在某一维度，且该维度同时触发跨资产背离，应升级提示级别。
