## 1. 核心方法：区段扫描（本次最重要的技术发现）

`lookup_field_reference` 的中文模糊检索**召回质量很差**——五轮迭代后仍有大量指标搜不出来：

- 搜「固定资产投资」→ 返回「建筑业:中间投入:固定资产折旧」等无关项
- 搜「M2同比」→ 空结果（正确关键词是「货币供应量M2:同比」）
- 搜「出口金额」→ 返回 CPI/PPI

**但 iFinD EDB 的指标 ID 按区段连续分配。** 实测确认：

```
M002043802  制造业PMI
M002043803  制造业PMI:生产
M002043804  制造业PMI:新订单
M002043805  制造业PMI:新出口订单
M002043806  制造业PMI:在手订单
M002043807  制造业PMI:产成品库存
...
```

**方法**：先由模糊检索锁定一个锚点 ID，再对锚点所在区段做**区间批量实测**（`THS_EDB` 支持分号批量），用返回的官方 `index_name` 反查全部指标。

**效果**：单次扫描把可用指标从 26 项提升到 49 项。

> 建议把「区段扫描」沉淀为固定流程：**任何新指标找不到时，先找同类锚点，再扫区段**。

## 6. 参数契约备忘（实测踩坑记录）

### 6.1 已确认的参数签名

```
THS_EDB   { indicators, begintime, endtime, param? }     indicators 分号分隔
THS_HQ    { thscode, jsonIndicator, jsonparam?, begintime, endtime }  字段分号分隔
THS_RQ    { thscode, jsonIndicator }
lookup_field_reference { function_name, keyword }
THS_DateQuery { market_code, param?, begintime, endtime }
THS_DR    { tableCode, filter, columns, format }
```

### 6.2 与手册记载不符之处（重要）

| 项 | 手册/文档记载 | **实测正确值** |
|---|---|---|
| 郑商所期货后缀 | `.ZCE`（`CF00.ZCE`） | **`.CZC`** —— `FG00.CZC`/`ZC00.CZC` 通过，`.ZCE` 全部 `-4210` |
| 沪深300 EDB 指标 | 未记载 | 存在 `M002845714`（EDB 亦可取指数） |
| `lookup_field_reference` 对 `THS_HQ` 的语义 | 「keyword 对 THS_BD/DS/HQ/RQ/EDB/DR 都有效」 | **对 HQ 返回的是字段名（open/close/ths_*），不是证券代码**，不能用于找标的 |

### 6.3 错误码处理约定

| 错误码 | 含义 | 可重试 |
|---|---|---|
| `-4001` | 无数据 | ❌ 按空结果处理 |
| `-209` | 参数或指标无效 | ❌ 需改参数 |
| `-4210` | 输入参数格式错误 | ❌ 需重构参数 |

### 6.4 EDB 返回值天然满足 Spec §12/§14

```json
{ "id": "M002834227", "index_name": "GDP:不变价:当季同比",
  "time": "2026-06-30",   // observation_date（观测期）
  "rtime": "2026-07-15 10:05:10",   // release_date（发布时刻）
  "value": "4.3" }
```

**`time` 与 `rtime` 原生分离** —— 不需要自己推导发布日，直接落库即可满足「observation_date / release_date 分离」的硬要求。
